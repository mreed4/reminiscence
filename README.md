# Reminiscence

This project began as a handwritten exercise in 2023 and has since evolved into an AI-enhanced React/Netlify app.

It now combines frontend state and UI logic with Netlify serverless functions for YouTube data fetching, while preserving the original learning-focused roots.

## Notes

- Started as a manual implementation and exploration.
- Later enhanced with AI-assisted development and cleanup.
- Uses Netlify functions for YouTube API calls and React for the UI.
